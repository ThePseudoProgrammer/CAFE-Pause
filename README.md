# PAUSE. — сайт спешелти-кофейни

Одностраничный адаптивный лендинг кофейни **PAUSE.**, расположенной в Свердловском (Московская обл.). Философия проекта — «сделай паузу»: замедлиться, выдохнуть и выпить хороший кофе.

## ✨ Возможности

- 📱 **Адаптивная вёрстка** — от широких мониторов до смартфонов
- ☕ **Интерактивное меню** — плавное раскрытие дополнительных позиций
- 🖼️ **Галерея с лайтбоксом** — плавное открытие и закрытие по клику, `Escape` или фону
- 📝 **Форма бронирования** — валидация имени, телефона, даты и времени в рамках часов работы
- 🕒 **Статус «Сейчас открыто / закрыто»** — рассчитывается по текущему времени
- 🛡️ **SVG-заглушки** — если изображение с Unsplash не загрузилось, подставляется брендированная заглушка
- 🔒 **Модальное окно политики конфиденциальности**
- 🎯 **Подсветка активного раздела** при прокрутке

## 🛠️ Стек

- HTML5
- CSS3 (Grid, Flexbox, CSS-анимации, `clamp()` для типографики)
- Vanilla JavaScript (ES5-совместимый, без сборки)
- Google Fonts: Playfair Display + Inter
